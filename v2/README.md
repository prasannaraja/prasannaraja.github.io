# Public Frontend v2

The active public portfolio and Digital Twin application is in [`my-career-twin/`](./my-career-twin/).

It uses React 19, TypeScript, Vite, Tailwind CSS, Redux Toolkit, and the Rust Axum API at `repos/private/api/v1/`.

```bash
cd my-career-twin
npm install
npm run dev
npm run build
```
